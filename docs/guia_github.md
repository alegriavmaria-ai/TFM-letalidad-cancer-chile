# Guía rápida: trabajar con este repositorio

## Flujo de trabajo básico

Cada vez que quieras guardar avances en el repositorio:
1. Edita o crea el archivo en GitHub (o desde tu computador con Git)
2. Escribe un mensaje breve describiendo qué cambiaste
3. Confirma los cambios (Commit changes)

## Estructura del proyecto

- data/processed/ → Datos ya filtrados de cáncer, listos para usar
- notebooks/ → Notebooks de análisis, uno por fase del TFM
- src/ → Scripts de procesamiento reutilizables
- docs/ → Notas metodológicas
- outputs/ → Gráficos y modelo final entrenado
